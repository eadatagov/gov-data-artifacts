# gov-data-artifacts

Repositorio de artefactos de gobierno de datos del programa de acompañamiento entre Trust Data Partners (TDP) y Andes Mining Corp (AMC).

## Propósito

Este repositorio versiona los artefactos del programa de gobierno de datos de AMC: Business Glossary, reglas de calidad de datos, políticas
de gobierno, artefactos de gobernanza de IA, decisiones de arquitectura y evidencia de auditoría.

## Cómo contribuir

1. Proponer un cambio en una rama nueva (ver módulo 03 del curso interno de Git para más detalle sobre el flujo de branching).
2. Solicitar revisión del Data Owner del dominio correspondiente.
3. Fusionar solo tras aprobación explícita.
